
# Manual de usuario

1. Abrir el archivo `src/index.html` en un navegador.
2. Ingresar el nombre del cliente.
3. Ingresar el teléfono.
4. Presionar "Registrar cliente".
5. Verificar el mensaje mostrado en pantalla.

Nota: en la versión inicial, el teléfono todavía no valida que se ingresen únicamente números.
