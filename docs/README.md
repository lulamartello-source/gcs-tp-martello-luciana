
# Gestor de Clientes

Sistema web básico para registrar clientes mediante su nombre y teléfono.

## Versión

v1.0 - Línea base inicial.

## Estructura

- `src/`: código fuente.
- `tests/`: pruebas.
- `docs/`: documentación del proyecto.

## Ejecución

Abrir el archivo `src/index.html` en un navegador.
